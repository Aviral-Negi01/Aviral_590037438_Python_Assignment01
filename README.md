# 🐍 Fundamentals of Python Programming

> Undergraduate Level · Practice-led Learning · No Prior Experience
> Required

A structured, eleven-session journey through the fundamentals of Python
programming. The course develops Python vocabulary, computational
reasoning, core data structures, control flow, iteration, and reusable
functions in a prerequisite-safe order.

**By Vibhu Gautam**

------------------------------------------------------------------------

## 📚 Learning Journey

From first expressions to reusable functions:

  -----------------------------------------------------------------------
  Stage                   Focus                   What You'll Learn
  ----------------------- ----------------------- -----------------------
  **01 · Foundations**    Read and write Python   Syntax, tokens,
                                                  identifiers,
                                                  expressions,
                                                  statements, operators

  **02 · Values**         Numbers and text        Numeric types,
                                                  variables, strings,
                                                  Unicode, indexing and
                                                  formatting

  **03 · Collections**    Model structured data   Lists, dictionaries,
                                                  tuples, files,
                                                  mutability

  **04 · Control**        Decide and repeat       Boolean logic,
                                                  conditions, loops,
                                                  iteration and
                                                  comprehensions

  **05 · Functions**      Structure and reuse     Functions, parameters,
                                                  return values,
                                                  validation, scope and
                                                  reuse
  -----------------------------------------------------------------------

------------------------------------------------------------------------

# 🗂️ Course Sessions

Eleven connected sessions designed to build concepts progressively.

## Session 01 --- Python Basics

**Topics covered:** - Python programming fundamentals - Tokens -
Keywords - Identifiers - Literals - Expressions - Statements -
Comments - Operators - Operator precedence - Operator associativity -
Unary, arithmetic, comparison and logical operators - Bitwise operators
and bits - Assignment operators - First Python programs - Basic input
and output

**Goal:** Understand Python's basic vocabulary and write simple Python
programs.

------------------------------------------------------------------------

## Session 02 --- Numeric Types and Variables

**Topics covered:** - Variables - Objects and values - Integers
(`int`) - Floating-point numbers (`float`) - Numeric expressions -
Arithmetic operations - Floor division - Modulo - Type conversion -
Assignment - Multiple assignment - Dynamic typing - Basic numeric
problem solving

**Goal:** Work confidently with numbers, variables and numerical
expressions.

------------------------------------------------------------------------

## Session 03 --- Strings and Text Processing

**Topics covered:** - Strings - Unicode text - String literals -
Indexing - Negative indexing - Slicing - String length - String
immutability - String methods - Searching and replacing text - String
concatenation - Formatting - f-strings - Escape characters

**Goal:** Store, access, process and format textual information.

------------------------------------------------------------------------

## Session 04 --- Lists

**Topics covered:** - Lists - Ordered collections - List indexing - List
slicing - Adding elements - Removing elements - List methods -
Mutation - Aliasing - Copying - Nested lists - List operations -
Membership testing - Iterating through lists

**Goal:** Use lists to store and manipulate collections of related data.

------------------------------------------------------------------------

## Session 05 --- Dictionaries

**Topics covered:** - Dictionaries - Keys and values - Key-value
mappings - Creating dictionaries - Accessing values - Adding and
updating entries - Removing entries - Dictionary methods - Traversal -
Iterating over keys and values - Records - Practical lookup patterns -
Membership testing

**Goal:** Represent structured information using key-value
relationships.

------------------------------------------------------------------------

## Session 06 --- Tuples, Files, and Mutability

**Topics covered:** - Tuples - Immutable sequences - Tuple indexing and
slicing - Tuple unpacking - Sequence unpacking - Mutable vs immutable
objects - File objects - Opening files - Reading text files - Writing
text files - File modes - Context managers - The `with` statement

**Goal:** Understand immutable sequences and safely work with text
files.

------------------------------------------------------------------------

## Session 07 --- Assignments and Syntax

**Topics covered:** - Names - Objects - Assignment - Object identity -
Equality - `is` vs `==` - References - Aliases - Multiple assignment -
Chained assignment - Unpacking assignment - Assignment forms - Common
syntax errors

**Goal:** Understand how Python names refer to objects and how
assignment works.

------------------------------------------------------------------------

## Session 08 --- Conditional Logic

**Topics covered:** - Boolean values - `True` and `False` - Boolean
expressions - Comparisons - Truthiness - `if` - `elif` - `else` - Nested
conditions - Logical operators - Short-circuit evaluation - Conditional
branching - Common logical mistakes

**Goal:** Make programs capable of making decisions based on conditions.

------------------------------------------------------------------------

## Session 09 --- Iteration and Loops

**Topics covered:** - Iteration - `for` loops - `while` loops - Loop
variables - Accumulators - Counters - Sentinels - `break` - `continue` -
Nested loops - Loop patterns - Iterating through collections - Common
loop mistakes

**Goal:** Repeat computations efficiently and solve repetitive problems.

------------------------------------------------------------------------

## Session 10 --- Iterators and Comprehensions

**Topics covered:** - Iteration protocol - Iterables - Iterators -
`iter()` - `next()` - Lazy evaluation - Generators - Generator
expressions - List comprehensions - Set comprehensions - Dictionary
comprehensions - Filtering and transformation - When to use
comprehensions vs ordinary loops

**Goal:** Understand Python's iteration model and write concise
collection-building code.

------------------------------------------------------------------------

## Session 11 --- Functions

**Topics covered:** - Functions - Function definitions - Function
calls - Parameters - Arguments - Positional arguments - Keyword
arguments - Return values - `return` - Default parameters - Validation -
Local and global scope - Variable scope - Reusable code - Function
design - Common function mistakes

**Goal:** Break programs into reusable, understandable and maintainable
components.

------------------------------------------------------------------------

# 🧠 Learning Method

Every session follows a consistent learning structure:

### 01 · Concept-first explanations

Important Python concepts are introduced with clear definitions before
moving to code.

### 02 · Executable examples

Examples are written as executable Python code so concepts can be tested
directly.

### 03 · Interpretation

Code output is examined and explained rather than simply memorized.

### 04 · Progressive practice

Problems increase gradually in difficulty while respecting the
prerequisites introduced earlier.

### 05 · Common mistakes

Typical syntax, logic and conceptual errors are identified and
explained.

### 06 · Recap

Each session reinforces the important ideas before moving to the next
topic.

-   Create and manipulate strings.
-   Use lists, dictionaries and tuples appropriately.

-   Use accumulators, counters and sentinel patterns.
-   Understand iterables and iterators.
-   Use comprehensions and generators.
-   Define and call reusable functions.

-   Understand basic variable scope.
-   Debug common syntax and logical errors.
-   Approach programming problems using computational reasoning.
